# Public training data used by milestone3/classifier.py

Curlie/DMOZ was the intended source but is not reachable from the build environment and has no maintained public dump.
Substitutes (downloaded from raw.githubusercontent.com, unmodified):

| File | Source | Mapped to category |
|---|---|---|
| hipo_universities.json (US entries only used) | https://github.com/Hipo/university-domains-list | competitor institution |
| ut1_forums.txt, ut1_social_networks.txt | https://github.com/olbat/ut1-blacklists (mirror of the Univ. Toulouse 1 Capitole lists, https://dsi.ut-capitole.fr/blacklists/) | forum/community |
| ut1_press.txt | same | earned media |
| ut1_jobsearch.txt, ut1_financial.txt | same | other |

No public source exists for BC-owned or education directory/ranking site.
Check each project's license before redistributing these files outside this private repo.
